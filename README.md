# SCAN-LLMs Ontology

SCAN-LLMs is an ontology developed as part of a doctoral research project.

## Description

SCAN-LLMs is an OWL ontology designed to provide an integrated representation of teaching and learning situations, students' autonomous use of Large Language Models (LLMs), and the knowledge required to analyze such use through ontological reasoning.

The ontology enables LLM uses to be contextualized according to pedagogical dimensions such as the pedagogical approach, learning moment, learning object, and learning objective. It also supports the inference of 21st-century skills associated with the learning tasks concerned.
